# Packlink

> Packlink is a multi-carrier shipping comparison and management platform for e-commerce. Its Packlink PRO API lets merchants and integrations compare carrier services, create shipments, print labels, track parcels, manage warehouses, and handle customs across carriers such as UPS, DPD, DHL, Evri, and Royal Mail.

This llms.txt was GENERATED by the API Evangelist enrichment pipeline from the repository's artifacts. The OpenAPI is DERIVED from Packlink's open-source e-commerce integration modules; request/response schemas are intentionally minimal.
